C++ Programming / Calculator Application console

Cute Calculator

A single-file C++17 command-line calculator built around a hand-written recursive descent expression parser. You type expressions; it tokenises and evaluates them with proper operator precedence instead of using eval or splitting strings on a delimiter.

  • Arithmetic with precedence, parentheses, unary minus, ^ powers, % modulo, factorial !
  • 33 math functions: sqrt, sin, ln, log, pow, root, hypot and more — each arity-checked
  • Constants (pi, e, tau) and ans for reusing the previous result
  • Several expressions per line separated by ;, plus commands: :help, :hist, :clear, :ans, :quit
  • Error handling by domain guard — division by zero, ln of a negative, wrong argument count — all caught as readable messages
  • ANSI colour output with Windows VT-mode enabling and an isatty check so piped output stays clean
C++17std::mapstd::vector function pointersrecursionexceptions <cmath>standard library only

Java Programming / POS Terminal desktop

Simple POS — Fast-Food Point of Sale

A Java Swing desktop interface for a fast-food ordering counter, built as a NetBeans Swing Forms project. The screen covers the cashier workflow: pick an item, build the order, take payment, and read the change back.

  • Numeric keypad layout with items 1–6 mapped to menu buttons
  • Order grid of ID / Item / Qty / Price using a JTable with DefaultTableModel
  • Receipt panel via JTextArea in a scroll pane
  • Transaction readout for Cash, Balance and Total, with a Pay action
  • Event-driven GUI work: ActionListener handlers wired per button
  • Layout work across GroupLayout and AbsoluteLayout (netbeans awtextra)

Web Development front-end

To-Do List

A small but complete task list that runs entirely in the browser — no framework, no build step. Adding, completing and deleting tasks all persist between reloads through localStorage.

  • Semantic structure with a clean HTML document outline
  • Flexbox layout, custom checkboxes and hover state transitions in CSS
  • DOM creation and re-rendering without a framework
  • One delegated click listener on the list handles both toggle and delete
  • JSON localStorage persistence with loadTodos / saveTodos
  • Empty state, Enter-key submission, input trimming, word-wrap on long tasks
